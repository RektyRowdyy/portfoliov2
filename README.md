# hridyadham.com

Personal portfolio website for [Hridya Dham](https://hridyadham.com).

## Stack

- Next.js 16 (App Router), React 19, TypeScript 5.8
- Tailwind CSS v4, shadcn/ui, Radix UI
- Motion for animations, visx + D3 for charts
- pnpm

## Getting started

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```
